Grouping and connection details

Set X-AgentBanter-Conversation to a stable ID to group an app's requests. Without it, each request is a separate recording. Responses include this ID and X-AgentBanter-Trace.

The upstream endpoint is {{ollama_url}}. This gateway forwards to that loopback endpoint and does not follow redirects. Whether a model executes locally or in Ollama's cloud depends on the model configured in Ollama. Browser apps on another origin need a same-origin backend connection.

Supported routes: native chat/generate, OpenAI-compatible chat completions, and model discovery. Responses are forwarded unchanged. Requests are limited to 32 MiB. Trace text previews are limited to 4 MiB per field and marked when shortened. Recordings stay on disk until removed by you.
